
# Student Management System

## About the Project
This is a beginner-level Student Management System project developed using Python.

The main purpose of this project is to learn Python programming and understand how a student management system works.

## Technology Used
- Python

## Project File
- std_management_sys.py

## How to Run
1. Install Python on your computer.
2. Download this repository.
3. Open Command Prompt in the project folder.
4. Run the following command:

```bash
python std_management_sys.py
```
